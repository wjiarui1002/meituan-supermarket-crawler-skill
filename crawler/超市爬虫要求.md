# 美团超市商品导出爬虫实现要求

## 1. 浏览器要求

必须使用 Playwright 连接已有 Chrome CDP：

- 默认 CDP：`http://127.0.0.1:9222`
- 默认复用 `chrome-profile/`
- 默认移动端 UA 和窄屏窗口
- 不主动新建浏览器窗口
- 不主动新建新标签
- 只操作当前已有页面标签

如需打开用户提供的超市链接，只能在当前标签内跳转。

## 2. 登录、定位与验证

程序不绕过登录、定位、验证码或风控。

当检测到以下情况时，必须暂停并提示用户手动处理：

- 未登录；
- 需要选择地址或定位；
- 出现验证码；
- 出现安全验证；
- 店铺页面无法访问；
- 接口返回访问受限。

用户完成处理后，程序继续从当前页面采集。

## 3. 接口探索方式

采集优先依赖真实页面网络响应：

- 监听当前页面 response；
- 串行处理响应；
- 识别商品、分类、店铺相关 payload；
- 保存关键原始响应；
- 不盲扫接口；
- 不暴力枚举参数；
- 不并发请求商品接口。

页面滚动只用于触发正常懒加载，滚动频率必须低。

## 4. 数据处理要求

商品数据先标准化为内部 JSONL，再导出 Excel。

内部商品字段包括：

- shop_name
- shop_url
- poi_id_str
- category_name
- category_id
- category_order
- product_id
- product_name
- product_image
- sales_count
- sales_text
- original_price
- current_price
- activity_price
- hand_price
- discount_info
- coupon_info
- third_category_name
- third_category_id
- product_review
- product_rating
- product_tags
- sold_out
- product_url
- sku_prices
- product_detail_json
- crawled_at

导出 Excel 时必须映射成参考文件字段。抓不到的字段留空，不允许臆造。

关键字段映射必须固定：

- `商品月售`：优先解析接口文本 `month_saled_content` / `sales_text`，如 `月售100+` 记为 `100`，`月售1.2万+` 记为 `12000`；不要把接口数值 `month_saled=0` 直接当作最终月售。
- `三级类目名称`、`三级类目id`：取商品原始字段 `standardCategorys` 中 `level=3` 的 `name` 和 `id`。
- `商品折扣`：取商品或 SKU 的 `promotion_info` / `promotion.promotion_text`，例如 `5.8折 限3份`、`买1份赠送...`。
- `优惠券`：取 `dynamic_act_labels[].sub_tags[].text` 或 `promotion.coupon` 文本，例如 `满19减8`、`不参加神券优惠`、`全店任选1件`。
- `到手价`：取 `unify_price.actual_price_info.actual_price` / `actual_price_str`；没有该字段时留空，不用活动价臆造。
- `活动价`：取 `unify_price.activity_info.activity_price`；没有时再回退到已有活动价格字段。
- `upc码`：优先取 SKU 的 `upccode` / `upc`。

Excel 主表字段顺序必须与参考文件保持一致，不允许新增、删除或重排字段。表头必须加粗，并用不同底色区分关键字段组：常规字段蓝色，价格/促销字段紫色，月售字段橙色，三级类目字段绿色。

## 5. 多规格规则

同一个商品如果存在多个 SKU：

- `商品详情`：合并成一行，规格用 `#` 拼接，价格和库存采用第一个 SKU 或接口主价格；
- `商品详情-多规格多行显示`：每个 SKU 一行，分别填写规格、sku_id、价格、活动价、库存、优惠。

## 6. 汇总与排行规则

月销售额暂按 `现价 * 商品月售` 估算。

汇总规则：

- 一级分类汇总：按 `一级分类` 聚合；
- 三级类目汇总：按 `三级类目名称` 聚合；
- SKU 数：对应 sheet 中参与计算的行数；
- 不动销 SKU：月售为 0 或缺失的行；
- 不动销率：`不动销 SKU / SKU 数`；
- 销售占比：该分类月销售额占总月销售额比例。

排行规则：

- 销量排行：按 `商品月售` 降序；
- 销售额排行：按估算销售额降序；
- 各类目前十：每个分类内按月售取前 10。

## 7. 输出要求

默认输出目录：`美团超市采集结果/`

输出文件：

- `shops.jsonl`
- `categories.jsonl`
- `products.jsonl`
- `interface-candidates.jsonl`
- `errors.jsonl`
- `state.json`
- `raw/*.json`
- `超市商品导出.xlsx`

Excel 必须包含与参考文件一致的 sheet 名称和主字段顺序。

## 8. 运行方式

推荐流程：

1. 双击 `启动可接管美团.command`；
2. 在 Chrome 中完成登录、定位和验证；
3. 打开目标超市链接，或在采集脚本中输入链接；
4. 运行超市采集脚本；
5. 等待低频滚动和接口监听完成；
6. 查看 `美团超市采集结果/超市商品导出.xlsx`。

命令行方式：

```bash
npm run supermarket -- \
  --cdp-url http://127.0.0.1:9222 \
  --url "美团超市链接" \
  --out-dir 美团超市采集结果 \
  --listen-ms 180000 \
  --scroll-steps 30 \
  --scroll-delay-ms 2000
```

## 9. 错误处理

要求：

- 单个字段缺失不影响整行；
- 单个商品解析失败记录错误并继续；
- 单个接口解析失败保存 URL 和错误；
- 写入 JSONL 后再更新状态；
- 程序结束前必须尝试导出 Excel；
- 如果没有采集到商品，应明确提示而不是生成误导性结果。

## 10. 合规边界

本工具只整理用户当前浏览器、当前登录状态、当前页面可正常访问的数据。

禁止：

- 绕过验证码；
- 绕过登录；
- 绕过风控；
- 高频请求；
- 批量攻击接口；
- 抓取当前页面权限之外的数据。
